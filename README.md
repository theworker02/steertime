# steertime

Steer filesystem time paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/steertime/

## Install / run

```bash
git clone https://github.com/theworker02/steertime.git
cd steertime
node src/cli.js
node --test
```
